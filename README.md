Sprint8-project

Este repositorio contiene el análisis realizado durante el sprint 8. - Explorando drivers de comportamiento en NovaRetail+

📂 Contenido del repositorio
notebooks/Project 8 - NovaRetail.ipynb → Notebook principal con exploración, limpieza de datos, análisis descriptivo, visualización de relaciones y análisis de correlaciones.

📚 Dataset utilizado
novaretail_comportamiento_clientes_2024.csv → Conjunto de datos con 15,000 registros y 12 variables relacionadas con información demográfica, comportamiento de compra, satisfacción, suscripción y generación de ingresos.

🧠 Objetivo del análisis
Explorar y evaluar la calidad de los datos.
Analizar variables demográficas y de comportamiento de los clientes.
Identificar patrones y relaciones entre las variables.
Evaluar qué factores presentan mayor asociación con los ingresos anuales.
Generar insights que contribuyan al diseño de estrategias de crecimiento y retención de clientes.

📈 Análisis realizados
Exploración y limpieza de datos con Pandas.
Análisis estadístico descriptivo.
Visualización de correlaciones mediante Heatmap.
Análisis de relaciones mediante Scatterplots.
Correlación de Pearson y Spearman.
Correlación punto-biserial.
Asociación entre variables categóricas mediante V de Cramér.
